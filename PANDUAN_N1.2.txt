NUSAMIND ZENITH N1.2 - ADVANCED AUTONOMY & DEPLOYMENT

1. Salin .env.example menjadi .env.
2. Isi AUTONOMY_AGENT_TOKEN dengan token lokal acak.
3. Buat NUSAMIND_VAULT_KEY 32-byte melalui PowerShell:
   $b=New-Object byte[] 32
   [Security.Cryptography.RandomNumberGenerator]::Fill($b)
   [Convert]::ToBase64String($b)
4. Jalankan npm install, npm run check, npm run build.
5. Jalankan dev.bat.
6. Buka autonomy.bat untuk menu Autonomy CLI.

Endpoint: http://localhost:3000/api/n1/autonomy
Header eksekusi: x-autonomy-token

KEAMANAN
- Force push memakai --force-with-lease dan membuat backup branch remote.
- Raw arbitrary shell tidak dieksekusi.
- Credential disimpan terenkripsi dan tidak dikembalikan API.
- Unverified MCP memerlukan sandbox wrapper untuk tool execution.
- Deployment production hanya tersedia pada Apex.
- Kill switch agent loop: buat file .nusamind/STOP.
