# Upload NusaMind Zenith N1.2 ke GitHub

Buat repository publik kosong bernama `NUSAMIND-ZENITH` pada akun `muhrafi-fsdev`. Jangan centang pembuatan README, `.gitignore`, atau license agar riwayat awal tidak bertabrakan.

Setelah ZIP diekstrak, jalankan `UPLOAD_ZENITH_TO_GITHUB.bat`. Script akan membuat Git repository lokal, commit awal, dan push ke branch `main`.

Repository belum menetapkan lisensi open-source. Jangan menambahkan badge atau file lisensi tanpa keputusan developer.
