# JSON Naming Standard

Semua JSON data memakai nama deskriptif `kebab-case`, tanpa nomor versi pada nama file. File konvensional tooling (`package.json`, `package-lock.json`, `tsconfig.json`) dipertahankan agar kompatibel dengan Node.js, npm, Next.js, dan TypeScript. Pemetaan rename tersedia di `data/release/r13.45/json-name-map.json`.
